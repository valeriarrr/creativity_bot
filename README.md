## Описание проекта

Telegram-бот «Креативный генератор» - помощник для придумывания идей и творческих задач. Бот по кнопкам выдаёт случайные идеи для контента, шаблоны мемов, готовые промпты для нейросетей, вопросы для брейнсторма и структуры для творческих текстов.

## Функциональные возможности

### Основной функционал
- 💡 Генератор идей для контента (10 заготовок, случайный выбор)
- 🖼 Шаблоны мемов (Drake, Distracted Boyfriend, This is fine)
- 🤖 Промпты для нейросетей (4 готовых описания для картинок)
- 🧠 Брейнсторминг (6 наводящих вопросов)
- 📋 Шаблоны для творчества (пост, Reels, сторителлинг, письмо, питч)

### Дополнительный функционал
- 🔄 Кнопка «Ещё» — повторная генерация без возврата в меню
- ⬅️ Кнопка «В меню» — быстрый возврат к главному меню
- 📖 Команда `/help` со списком всех команд

## Требования к системе
- **Python:** 3.10.11 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** `python-telegram-bot`

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone ССЫЛКА БУДЕТ ПОЗЖЕ
cd creativity_bot
```

### 2. Создание и активация виртуального окружения
Windows:
```bash
python -m venv venv
venv\Scripts\activate
```
macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```
